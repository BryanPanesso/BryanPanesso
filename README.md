**Full Stack Developer** · *May 2024 – Present* · [blitzapp.pro](https://blitzapp.pro/)

Enterprise SaaS for restaurant & F&B operations: POS, inventory, cash control, and real-time ops.

- 📦 **Inventory Management Architecture** — End-to-end inventory control with **31 REST endpoints**, React/TypeScript UI, and **FEFO** lot picking for perishable stock.
- 🖥️ **Complex Frontend UIs** — Split-bill checkout, Ant Design systems, and Zod-validated forms for high-traffic point-of-sale flows.
- 🔐 **Biometric System Integration** — Windows desktop bridge with **.NET + WebSockets + ZKTeco SDK + SourceAFIS**, secured with **AES-GCM**; **100% test coverage**.
- 📴 **Offline POS & PWA** — Offline-sales queue, **Workbox** caching, and **IndexedDB** persistence so sales never stop when connectivity drops.
- 🖨️ **Thermal Printing** — Secure certificate-based printing via **QZ Tray** for tickets, kitchen commands, and delivery slips.
